# SIH 26067 — Ocean Intelligence Platform Backend

> ⚠️ **DEMO / SIMULATED DATA** — not affiliated with INCOIS, MoES, or any operational forecast system.

## Overview

FastAPI backend that reads NetCDF ocean model data via xarray and serves it to the React 3D visualization frontend.

```
React (Three.js / R3F)
        ↓  HTTP/JSON
FastAPI (Python 3.11)
        ↓
xarray (lazy evaluation)
        ↓
NetCDF files (backend/data/)
```

---

## Requirements

- Python 3.11+
- pip

---

## Setup

### 1. Create a virtual environment

```bash
# From the repo root
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r backend/requirements.txt
```

### 3. Generate the demo dataset

```bash
python scripts/generate_demo_nc.py
```

This creates `backend/data/demo/demo_ocean.nc` (approx 800 KB).

---

## Running the Backend

```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

The server starts at **http://localhost:8000**

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/health` | Health check |
| GET | `/api/v1/datasets` | List available datasets |
| GET | `/api/v1/datasets/{id}` | Dataset detail + metadata |
| GET | `/api/v1/ocean/variables` | Variable catalogue |
| GET | `/api/v1/ocean/times` | Available timestamps |
| GET | `/api/v1/ocean/depths` | Available depth levels |
| GET | `/api/v1/ocean/field` | 2D field slice (lat × lon) |
| GET | `/api/v1/ocean/value` | Point query (nearest neighbour) |
| GET | `/api/v1/ocean/profile` | Depth profile at location |
| GET | `/api/v1/observations` | In-situ observation list |
| GET | `/api/v1/observations/{id}/profile` | Observation depth profile |

### Example requests

```bash
# Health
curl http://localhost:8000/api/v1/health

# List datasets
curl http://localhost:8000/api/v1/datasets

# Temperature field at 100 m, 12:00 UTC
curl "http://localhost:8000/api/v1/ocean/field?variable=temperature&depth=100&time=2026-08-28T12:00:00Z"

# Point value
curl "http://localhost:8000/api/v1/ocean/value?latitude=15.0&longitude=65.0&depth=0&variable=temperature&time=2026-08-28T12:00:00Z"

# Depth profile
curl "http://localhost:8000/api/v1/ocean/profile?latitude=15.0&longitude=65.0&variable=temperature&time=2026-08-28T12:00:00Z"

# Observations
curl http://localhost:8000/api/v1/observations

# Observation profile
curl http://localhost:8000/api/v1/observations/ARGO_6902880/profile
```

```python
    # Add real INCOIS files here for Phase 4:

```

## Frontend Integration

Set environment variables in `.env.development` (repo root):

```env
VITE_API_BASE_URL=http://localhost:8000
VITE_DATA_SOURCE=api
```

Set `VITE_DATA_SOURCE=mock` to disable the backend and use the built-in demo data (useful when the backend is not running).

- No authentication
- No real-time streaming

- No database — observations are hardcoded demo data
